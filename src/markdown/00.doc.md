### 主题一：Vue 3 响应式全景实验室 (Vue 3 Reactivity Lab)

- **比喻**：**“细胞的神经反射系统”**。外界刺激（数据变化）发生时，细胞（DOM）如何不假思索地做出局部精准反应？
- **核心痛点**：很多开发者只知道 `ref` 和 `reactive`，但在面对“数据变了视图不更新”、“解构丢失响应式”、“内存泄漏”等问题时束手无策。
- **推荐细分实验设计（路由划分）**：
  1.  `ref-vs-reactive`：究竟什么时候用 `ref`，什么时候用 `reactive`？（展示各自的局限与底层代理原理）。
  2.  `computed-setter`：计算属性不仅能只读，还能通过 `set` 拦截器实现逆向修改。
  3.  `watch-vs-watcheffect`：对比普通侦听与立即执行侦听，探讨如何正确进行异步副作用清除（`onCleanup`）。
  4.  `shallow-reactivity`：深度响应式 vs 浅层响应式（`shallowRef` / `shallowReactive`），展示如何通过手动触发更新（`triggerRef`）来优化巨量数据的渲染性能。
  5.  `to-refs-to-raw`：如何在保持响应式的前提下将对象“安全拆包”（`toRefs`），以及如何在需要时临时“脱去”响应式外壳以优化性能（`toRaw`）。
- **高阶看点**：
  - 演示 Vue 3.5 新增的 **`onWatcherCleanup`** 的使用场景。
  - 对比 Vue 2（`Object.defineProperty`）与 Vue 3（`Proxy`）的底层差异。

### 主题二：Composable 最佳实践工坊 (Vue 3 Composable Workshop)

- **比喻**：**“变形金刚的模块化装备”**。组件不再是一个臃肿的实体，而是由各种可拆卸、可复用的“超能力模块”组装而成的轻量级躯壳。
- **核心痛点**：很多人把组合式 API（Composition API）写成了“换了皮的 Options API”（即把所有的 ref、computed 和 function 堆在一个巨大的 `setup` 里，没有做任何逻辑抽离）。
- **推荐细分实验设计（路由划分）**：
  1.  `use-local-storage`：状态与持久化。封装一个与 `localStorage` 自动同步的响应式变量。
  2.  `use-fetch`：异步数据流。封装一个带 `loading`、`error`、支持中止请求（`AbortController`）的通用请求 Composable。
  3.  `use-event-listener`：DOM 与生命周期自治。在 Composable 中自动绑定和解绑 window 事件，避免因遗忘注销导致内存泄漏。
  4.  `use-debounce-ref`：性能防抖。封装一个防抖响应式变量，输入框高频输入时延迟触发更新。
  5.  `use-intersection-observer`：视口监听。封装元素曝光逻辑，实现图片懒加载、无限滚动加载。
- **高阶看点**：
  - 深刻理解“有状态的 Composable”（如管理共享状态）与“无状态的 Composable”（如纯工具函数）的区别。
  - 探讨如何编写一个符合企业级标准的、优雅且类型安全的 Composable 库。

### 主题三：极致性能与内置组件实验室 (Performance & Built-in Components Lab)

- **比喻**：**“空间折叠器与时空冻结箱”**。打破常规 DOM 树的层级结构，或者在组件“死亡”时将其记忆完美冻结。
- **核心痛点**：项目越做越大后出现页面卡顿；Modal 弹窗被父组件的 `overflow: hidden` 截断；多标签页切换时表单数据频繁被清空。
- **推荐细分实验设计（路由划分）**：
  1.  `keep-alive`：组件缓存。演示如何冻结页面状态，深入理解 `onActivated` 和 `onDeactivated` 生命周期的应用。
  2.  `teleport`：传送门。演示如何将 Modal、Drawer 传送至 `body` 根节点，彻底解决 CSS 样式污染和层级遮挡问题。
  3.  `async-components-suspense`：异步组件与骨架屏。配合 `defineAsyncComponent` 和 `<Suspense>`，优雅地展示组件加载中的过渡效果。
  4.  `v-once-v-memo`：静态标记与缓存指令。展示在面对上千条长列表、图表渲染时，如何利用 `v-once` 和 `v-memo`（Vue 3 新增）实现局部更新性能翻倍。
- **高阶看点**：
  - 探讨如何通过虚拟滚动（Virtual List）结合 Vue 3 渲染特性突破 DOM 渲染极限。

### 主题四：权限攻坚与自定义指令实验室 (Directives & Permissions Lab)

- **比喻**：**“特工的通行证系统”**。根据用户身上的身份标签，动态给 DOM 元素赋予各种行为或直接让其在页面中“隐形”。
- **核心痛点**：在企业级后台管理系统中，按钮级权限、图片防盗、点击防抖、图片懒加载等高频业务需求如何以最解耦、最干净的代码去实现。
- **推荐细分实验设计（路由划分）**：
  1.  `v-permission`：按钮权限控制（RBAC 基础）。根据当前用户角色，动态决定一个按钮是渲染、禁用还是直接移除。
  2.  `v-debounce`：防抖指令。通过自定义指令直接为任何一个普通 button 绑定防抖点击行为，防止用户高频重复提交表单。
  3.  `v-lazy-image`：图片懒加载指令。当图片滚动到可视区域时再进行加载，优化首屏性能。
  4.  `v-watermark`：全屏/局部水印指令。通过 Canvas 动态生成水印并防篡改（监听 DOM 变化防删除）。
- **高阶看点**：
  - 掌握自定义指令的生命周期钩子（Vue 3 中自定义指令的钩子已与组件生命周期完全对齐）。
  - 通过 `MutationObserver` API 实现水印被恶意删除后的“自我修复”。
