## 2. 配置路由

创建 `src/router/index.ts`：

```ts
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    {
      path: '/',
      name: 'Home',
      component: () => import('@/views/HomeView.vue'),
      meta: { title: 'Home' },
    },
  ],
})

router.beforeEach((to) => {
  const title = to.meta.title
  document.title = title ? `${title} | vue3-communication-lab` : 'vue3-communication-lab'
})

export default router
```

**逐行讲解：**
- `createWebHistory()` — HTML5 历史模式（无 # 号）
- `routes` 数组定义所有路由
- `component: () => import(...)` — 路由懒加载，按需加载页面
- `meta.title` — 路由元信息，用于动态设置页面标题
- `beforeEach` — 导航守卫，每次跳转前更新页面标题

## 5. 创建页面通用布局组件

为了让每个演示页面有统一的「介绍 - 演示 - 代码」三栏结构，先创建布局组件。

创建 `src/components/ComponentDemoLayout.vue`：

```vue
<script setup lang="ts">
import { ref } from 'vue'

type Tab = 'introduction' | 'demo' | 'code'
const activeTab = ref<Tab>('introduction')

const tabs: { key: Tab; label: string }[] = [
  { key: 'introduction', label: '知识点介绍' },
  { key: 'demo', label: '在线演示' },
  { key: 'code', label: '核心代码' },
]
</script>

<template>
  <div class="demo-layout">
    <div class="tabs" role="tablist">
      <button
        v-for="tab in tabs"
        :key="tab.key"
        :class="['tab-btn', { active: activeTab === tab.key }]"
        :aria-selected="activeTab === tab.key"
        role="tab"
        @click="activeTab = tab.key"
      >
        {{ tab.label }}
      </button>
    </div>
    <div class="tab-content">
      <div v-if="activeTab === 'introduction'" class="tab-panel">
        <slot name="introduction" />
      </div>
      <div v-if="activeTab === 'demo'" class="tab-panel">
        <slot name="demo" />
      </div>
      <div v-if="activeTab === 'code'" class="tab-panel">
        <slot name="code" />
      </div>
    </div>
  </div>
</template>
```

**讲解三个 named slot：**
- `<slot name="introduction">` — 知识点文档
- `<slot name="demo">` — 可交互的演示
- `<slot name="code">` — 源码展示

## 6. 创建根布局 App.vue

创建 `src/App.vue`：

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { useRouter } from 'vue-router'

const router = useRouter()
const isMenuOpen = ref(false)
const routes = router.getRoutes().filter(r => r.path !== '/')
</script>

<template>
  <div class="app-container">
    <button class="menu-toggle" @click="isMenuOpen = !isMenuOpen">
      {{ isMenuOpen ? '✕' : '☰' }}
    </button>
    <nav :class="['sidebar', { open: isMenuOpen }]">
      <h2 class="sidebar-title">Vue 3 组件通信</h2>
      <router-link
        v-for="route in routes"
        :key="route.path"
        :to="route.path"
        class="sidebar-link"
        @click="isMenuOpen = false"
      >
        {{ route.meta?.title || route.name }}
      </router-link>
    </nav>
    <main class="content">
      <router-view v-slot="{ Component }">
        <transition name="fade" mode="out-in">
          <component :is="Component" />
        </transition>
      </router-view>
    </main>
  </div>
</template>
```

**教学要点：**
- `router.getRoutes()` 获取所有路由配置，自动生成导航菜单
- `router-link` 是 Vue Router 的声明式导航组件
- `<transition>` 实现页面切换动画
- 移动端响应式设计（侧边栏折叠）
