# 课时 01：项目初始化

> 目标：创建一个 Vite + Vue 3 + TypeScript 项目骨架

---

## 1. 创建项目

打开终端，在目标目录下执行：

```bash
pnpm create vite vue3-communication-lab --template vue-ts
cd vue3-communication-lab
pnpm install
pnpm add vue-router@4 pinia mitt markdown-it
pnpm add -D @types/markdown-it
```

**逐行解释：**
- `create-vite` 是 Vite 的脚手架工具，`--template vue-ts` 生成 Vue 3 + TypeScript 模板
- `vue-router` 是 Vue 官方路由，`pinia` 是官方状态管理
- `mitt` 是轻量级事件总线（替代已废弃的 `$on` / `$emit`）
- `markdown-it` + `@types/markdown-it` 用于渲染 Markdown 教学文档

## 2. 初始项目结构

创建完成后，让学生观察项目结构：

```
vue3-communication-lab/
├── src/
│   ├── App.vue
│   ├── main.ts
│   ├── style.css
│   ├── components/
│   │   └── HelloWorld.vue         # 可以删除
│   └── assets/
│       └── vue.svg                # 可以删除
├── index.html
├── vite.config.ts
├── tsconfig.json
├── tsconfig.app.json
└── package.json
```

**教学要点：**
- `vite.config.ts` 是构建配置文件
- `src/main.ts` 是应用入口
- `src/App.vue` 是根组件
- `index.html` 是 HTML 入口，`<div id="app">` 是挂载点

## 3. 清理脚手架

删除不需要的模板文件：

```bash
Remove-Item src/components/HelloWorld.vue
Remove-Item src/assets/vue.svg
```

## 4. 配置 Vite（可选但推荐）

`vite.config.ts` 添加路径别名和端口：

```ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { resolve } from 'path'

export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': resolve(__dirname, 'src'),
    },
  },
  server: {
    port: 5200,
  },
})
```

`tsconfig.app.json` 确保有路径别名配置：

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

## 5. 验证项目能正常运行

```bash
pnpm dev
```

打开浏览器访问 http://localhost:5200，看到空白页面（只有一个 `<div id="app">`）即表示成功。

## 6. 初始化 git 提交

```bash
git add .
git commit -m "feat: 初始化 Vite + Vue3 + TS 项目"
```
