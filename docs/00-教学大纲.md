# Vue 3 组件通信 — 教学大纲

> 总课时：12 课时（每课时约 45-60 分钟）
> 面向对象：已掌握 HTML / CSS / JavaScript 基础，了解 Vue 3 基本语法的学生
> 教学方式：教师带领手敲代码，边讲边练

---

## 课程定位

本课程聚焦 **Vue 3 组件通信**，这是 Vue 开发中最核心也最容易被忽视的技能。课程不追求大而全，而是逐个击破每一种通信模式，让学生在动手实践中理解每种模式的适用场景、实现方式和注意事项。

---

## 课时安排总览

| 课时 | 标题 | 内容概要 | 核心知识点 |
|------|------|---------|-----------|
| 01 | 项目初始化 | 用 Vite 创建项目，安装依赖 | `create-vite`、Vue 3 + TS、pnpm |
| 02 | 应用骨架搭建 | 路由 + 全局布局 | `vue-router`、路由配置、动态侧边栏 |
| 03 | **Props** — 父传子 | 父组件向子组件传递数据 | `defineProps`、单向数据流、TS 类型约束 |
| 04 | **Emit** — 子传父 | 子组件向父组件发送消息 | `defineEmits`、事件触发与监听 |
| 05 | **v-model** — 双向绑定 | 父子组件双向数据同步 | `modelValue` / `update:modelValue`、多 v-model |
| 06 | **$attrs** — 透传属性 | 跨层级传递属性 | `inheritAttrs`、`v-bind="$attrs"`、`useAttrs` |
| 07 | **ref + defineExpose** | 父组件调用子组件方法 | 模板 ref、`defineExpose`、`InstanceType` |
| 08 | **provide/inject** | 跨层级依赖注入 | `provide`、`inject`、`InjectionKey`、`readonly` |
| 09 | **Pinia** — 全局状态 | 兄弟/无关组件共享状态 | `defineStore`、`storeToRefs`、getter |
| 10 | **Mitt** — 事件总线 | 任意组件间通信 | `mitt`、`emit` / `on` / `off`、生命周期清理 |
| 11 | **Slot** — 插槽分发 | 组件内容分发机制 | 具名插槽、作用域插槽、后备内容 |
| 12 | 总结与回顾 | 对比所有通信模式，串联回顾 | 场景 vs 模式匹配、架构思维 |

## 教学节奏建议

```
课时 01 ── 项目初始化（轻量，约 30 分钟）
   │
课时 02 ── 应用骨架（较重，约 60 分钟）
   │
课时 03~11 ── 核心通信模式（每个约 45 分钟，含练）
   │          每个模式的固定流程：
   │          ① 场景引入（5min）
   │          ② 手写代码（20min）
   │          ③ 运行验证（5min）
   │          ④ 知识点讲解（10min）
   │          ⑤ 小结/提问（5min）
   │
课时 12 ── 总结回顾（约 30 分钟）
```

---

## 教学模式说明

每个通信模式的课时按统一结构设计：

1. **生活场景引入** — 用现实类比解释为什么需要这种通信
2. **代码实战** — 教师写一行学生跟一行，逐行解释
3. **运行验证** — 即时查看效果，建立因果关联
4. **知识点总结** — 提炼核心 API 和注意事项
5. **课后思考** — 1~2 个开放性问题，引导深入理解

> **核心原则**：不提前给完整代码，让学生跟着写、跟着想、跟着犯错。错误是最好的学习机会。
